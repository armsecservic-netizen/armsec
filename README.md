# ArmSec — сайт, AI-консультант и CRM

Внутри: сайт на трёх языках (հայերեն / русский / English) с прайсом и фото, корзина, форма заявки,
AI-консультант, панель управления `/admin` (заявки, диалоги бота, цены и фото, обучение бота, контакты).
Все данные хранятся в базе PostgreSQL на Railway и не пропадают при перезапуске.

## Как запустить на Railway (10 минут)

1. **Загрузите проект на GitHub.** Создайте новый репозиторий (можно приватный), нажмите «Add file → Upload files»
   и перетащите **содержимое** папки armsec (папки `public`, `server` и файлы рядом с ними), не саму папку.
   Всего около 17 файлов, это в пределах лимита GitHub (100 файлов и 25 МБ на файл).
2. **Создайте проект на Railway.** railway.com → New Project → Deploy from GitHub repo → выберите репозиторий.
3. **Добавьте базу данных.** В проекте нажмите «+ Create» → Database → PostgreSQL.
4. **Задайте переменные.** Откройте сервис сайта → Variables → добавьте:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Railway подставит адрес базы сам)
   - `ADMIN_PASSWORD` = ваш пароль для панели управления
   - `SESSION_SECRET` = любая длинная случайная строка (например, 40 букв и цифр)
   - `ANTHROPIC_API_KEY` = ключ Claude API (console.anthropic.com → API Keys). Без ключа бот работает
     в режиме быстрого поиска по каталогу, без AI.
   - по желанию `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-5-5`; дешевле — `claude-haiku-5-5`)
5. **Откройте сайт.** Сервис → Settings → Networking → Generate Domain. Чтобы подключить свой домен
   (например, armsec.am), там же нажмите Custom Domain и пропишите у регистратора домена запись CNAME,
   которую покажет Railway.
6. **Войдите в панель:** `https://ваш-сайт/admin`, пароль из `ADMIN_PASSWORD`.

## Telegram: заявки, диалоги и ваш личный помощник

1. В Telegram напишите @BotFather → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение — он ответит вашим chat id (или откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. В Railway → Variables добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (несколько менеджеров — через запятую: `111,222`).
4. Нужен домен сайта: Railway подставит его сам (`RAILWAY_PUBLIC_DOMAIN`), для своего домена задайте `PUBLIC_URL=https://armsec.am`.

Что приходит в Telegram:
- каждая заявка (с формы, опроса, от консультанта, партнёрская) — со ссылкой на панель и на переписку;
- каждый вопрос посетителя и ответ консультанта (`TG_CHATS=first` — только первый вопрос, `TG_CHATS=off` — выключить).

Что можно писать боту (нужен `ANTHROPIC_API_KEY`):
- «Составь прайс на 8 камер 4 Мп для склада» → бот подберёт и пришлёт ссылку на красивый прайс-лист (печать / PDF), её можно отправить клиенту;
- «Покажи новые заявки», «Заявку 15 в работу, перезвонить завтра»;
- «Поставь цену DS-2CD1043G2-LIU 28000», «Сделай скидку на …»;
- «Последние диалоги на сайте».
Команды: `/leads` — новые заявки, `/chats` — диалоги, `/chat_ID` — вся переписка.

## Ваша CRM

Каждая заявка (с формы, от консультанта, партнёрская) автоматически уходит в вашу CRM
(`crma-production.up.railway.app`): создаётся лид с именем и контактом, а в Инбокс приходит сообщение
с подробностями — товары, сумма, комментарий. Переписка посетителя с консультантом тоже идёт в Инбокс
(канал `website`), одна переписка — один диалог. Ключ уже вписан; чтобы поменять, задайте в Railway
переменные `CRM_URL` и `CRM_KEY`, чтобы отключить — `CRM_URL=off`.

## Панель управления `/admin`

- **Заявки:** все заявки с сайта и от консультанта, статус (новая / в работе / закрыта), заметка менеджера,
  кнопка «Диалог» — переписка клиента с ботом до заявки, выгрузка в Excel (CSV).
- **Диалоги:** все переписки бота с посетителями — что спрашивали и что бот ответил.
- **Товары и цены:** поиск, смена цены и старой цены (скидка), загрузка фото, скрыть / удалить, добавить товар.
- **Обучение бота:** приветствие на 3 языках, «О компании», «Правила и стиль», «Вопросы и ответы».
- **Контакты:** телефон, WhatsApp, e-mail, Facebook, Telegram/Viber, адрес, часы работы.

## Как обновить прайс

Цены можно менять в панели. Если пришёл новый прайс-лист целиком, замените `public/catalog.json`
и фото в `server/photos-*.json` (их готовит Claude из Excel-файлов) и загрузите на GitHub — Railway обновит сайт сам.
Изменения цен, сделанные в панели, сохраняются в базе и накладываются поверх прайса.

## Стоимость

- Railway: тариф Hobby — от $5 в месяц (сайт + база).
- Claude API: оплата по использованию; один диалог обычно стоит несколько центов. Лимит расходов
  можно задать в console.anthropic.com → Limits.

## Запуск на своём компьютере (для разработчика)

```
npm install
DATABASE_URL=postgres://... ADMIN_PASSWORD=... ANTHROPIC_API_KEY=... npm start
```
Сайт откроется на http://localhost:3000 (нужен Node.js 20+ и PostgreSQL).
